# Beam 0.7.0 validation — 30 October 2026

The final source suite passed 211 network-free automated tests. It covers existing coding, document/CAD generation, integrations, Crew, privacy, Codespaces transport and the persistent coordinator. The release report next to the installer records the final pass and packaging results.

New checks cover remote file edits and real generated documents; no local execution fallback; Ask/Edit/Plan and trusted-command boundaries; transport cancellation, including blocked stdin; upload limits and single-use review; helper environment isolation; worker version checks; local API tokens/origins; cloud credential consent; private-transfer review; durable avatars and metadata removal; task ownership; cloud disconnect restrictions; cached events and accurate offline states; legacy import; and restoring PC file tools.

An independent coordinator fixture finishes a real file task after desktop services close. Privacy checks capture every model payload: sensitive values are redacted, a localhost-model summary stays in the desktop database, and neither the summary nor original sensitive result enters subsequent model context. Cloud RPC is simulated in these tests. The coordinator itself runs with the real Store, Agent and Crew components.

Browser checks use local model fixtures and a headless installed Chrome. They exercise team delegation/Lead review and file output, profile and brief editing, approval/question/privacy pauses, stop, disconnection, preserved Studio drafts, light/dark rendering and responsive widths. The avatar workflow checks all ten options, shape/colour/face selection, uploaded image cropping, saved pictures after reload and job presets. Computer controls verify immediate dialog display during delayed discovery, browser device-code sign-in UI, worker installation, one-request activation, separate PC/cloud drafts, saved-target return, no idle polling, permission drafts, credential consent and Cloud Crew disconnect. Zero JavaScript errors are required.

The seven core modules inside the EXE were compared structurally against freshly compiled saved sources; their executable code, constants and signatures match. The build now recompiles app modules from source to prevent stale development caches.

The frozen-app probe checks version 0.7.0, no bundled model key, six profiles, drafts/stopping/history isolation, local API guards, avatar persistence, This PC as default, matching static assets, official GitHub CLI 2.103.3 and the source hashes inside the bundled worker ZIP. Self-test creates and reopens ten document/CAD outputs and checks external Python execution. The packaging report records its result.

The per-user NSIS installer retains the Installed apps uninstall entry. Isolated /VERIFY installation and removal suppress production registration/shortcuts and do not overwrite the user's existing Beam. Program files are removed; user projects/data are preserved. Uninstall does not delete a Codespace or cancel background cloud jobs.

Not verified against a live user Codespace: GitHub browser authentication, SSH provisioning, Linux user/permission setup, detached Unix-socket process lifetime and actual provider idle-stop behavior. They require the user's GitHub account and a running standard Codespace; this Windows host has no Linux environment. Automated fixtures verify routing and coordinator behavior, not those external account prerequisites. Google OAuth also requires the user's credentials. Real local Ollama weights were not available during this release validation; localhost protocol/model-origin fixtures cover the boundary. Earlier releases tested live Beam model requests, but this release does not claim a new live cloud-account test.

Provider idle timeouts, 12-hour session limits, allowances and account policies constrain background work. No fake keepalive, unlimited hosting, automatic billing purchase or permission bypass is included. Browser/MCP and persistent servers remain PC features. Privacy detection is heuristic; remote-stored material is already on GitHub infrastructure. Geometry checks do not certify visual resemblance, printable fits or mechanical safety.
